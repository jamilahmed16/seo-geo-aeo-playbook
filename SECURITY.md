# Security Policy

This repository contains documentation only. It holds no code that runs and no credentials.

## Reporting a problem

If you find sensitive information, such as a leaked key, a client name or private data, in this repository, please report it privately:

- Use GitHub's "Report a vulnerability" option under the Security tab, or
- Contact [Jamil Ahmed](https://jamilahmed.com).

Please do not open a public issue for sensitive findings. I aim to respond within 5 business days and to remove confirmed sensitive content promptly.
