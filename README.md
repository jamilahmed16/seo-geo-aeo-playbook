# SEO, GEO and AEO Playbook

A practical, vendor-neutral playbook for building and fixing sites so they rank in Google and get cited by AI search engines (Google AI Overviews, ChatGPT, Perplexity).

Distilled from real WordPress modernization work at [Reinforce Lab Limited](https://reinforcelab.com). Client names, data and internal decisions are removed. What remains are the standards, decision rules and checklists.

## What is inside

| File | Use it to |
|---|---|
| [01-build-standard.md](01-build-standard.md) | Gate every page against technical SEO, schema, Core Web Vitals and the GEO/AEO layer before it ships |
| [02-crawl-waste-playbook.md](02-crawl-waste-playbook.md) | Diagnose and fix junk URLs that burn crawl budget and keep real pages unindexed |
| [03-url-disposition-framework.md](03-url-disposition-framework.md) | Decide keep, rewrite, consolidate, redirect or retire for every URL in a migration |

## Who it is for

SEO leads, in-house marketers, agencies and founders who run a content site or a WordPress build and want a repeatable standard instead of ad-hoc fixes.

## Principles

1. Evidence before action. No change without a data signal.
2. Reversible first. Prefer fixes you can roll back in one step.
3. Real facts only. Never invent metrics, results or schema claims.
4. Build pages a crawler can parse, a human can convert on, and an LLM can quote.
